## Why the one-vector enumeration is exhaustive

For an even integral parent G of determinant d, write A=adj(G). A saturated one-vector extension can be written using an integer pairing column p and an even last diagonal n. Its Schur complement and determinant are

`s=n-p^T G^{-1}p >0`, `D=nd-p^T A p`.

Changing the new generator by a parent vector allows p to be chosen as a shortest representative of its dual discriminant class. This change preserves the generated lattice and the perpendicular dual vector. Both extension implementations enumerate every such class, and then every even diagonal n consistent with the requested determinant interval. Diagonal n is not restricted to 6. Thus extensions with a longer necessary new basis vector are included.

Fingerprints `A p modulo d` identify exactly the d discriminant classes. The rational ellipsoid enumeration eventually finds all d classes. Since the entire ball through that bound is enumerated, the least norm seen for each class is its true global minimum. A count of d representatives without ball completeness would be insufficient; here the recursive LDL enumerator supplies ball completeness.

For every positive integer m with `m^2 s<6`, the code tests `m^2 s+mu(m a)>=6`. All remaining m are automatic; negative m have the same norm. This includes multiples at the order of a, where the glue class becomes zero. The condition is necessary and sufficient for the child's squared minimum to be at least 6, assuming the parent minimum condition. The induction begins at `[6]`.

The exact vector enumerator traverses the LDL coordinates from last to first. Each remaining quadratic summand is nonnegative, and its integer interval is obtained from an exact rational square bound followed by `isqrt`; the conversion is exact because the squared integer numerator has an integral value. There is no inward floating rounding or heuristic vector cap. The only covering-bound guard raises an error if unexpectedly exceeded; it cannot silently omit classes.

## The optimized dual test and lifting prunes

The original implementation enumerates the child dual and directly checks that the perpendicular dual vector is shortest. The optimized implementation tests the equivalent condition using parent dual vectors. For a nonzero parent pairing q, minimizing the last dual coordinate gives the integer criterion

`D(q^T A q) + dist(p^T A q, d Z)^2 >= d^2`.

Only q with `D(q^T A q)<d^2` can violate this. Therefore enumerating parent-dual vectors through squared norm `d/D_low` covers every possible violating q for every candidate determinant at least D_low. Keeping one of q and -q is safe. For q=0, the perpendicular dual vector itself supplies the minimum among nonzero last coordinates, so no omitted q=0 case can invalidate the test. The code's scaling and strict/equality comparisons agree with this derivation.

A parent-dual vector of squared norm lambda can be lifted to a child-dual vector of norm at most `lambda+1/(4s)`. If the perpendicular vector is shortest, `1/s<=lambda+1/(4s)` implies `s>=3/(4lambda)`. In a certified shortest-dual flag, `lambda=d_previous/d_parent`, giving

`d_next >= 3 d_parent^2/(4 d_previous)`.

Every prune uses this as a necessary lower bound and removes only a case whose lower bound is strictly above the following upper window. Equality is retained. The optimized kernel increases its lower determinant endpoint by the ceiling of this same necessary bound, which is valid.

The final 3819 records were independently checked arithmetically by `check_global_rank10_windows.py`; every lifting inequality rules out d10<=54672. The least such lower bound is `12966723/212`, already above the target. This final check is not, on its own, evidence that the 3819 input records exhaust all cases: that depends on the full parent chain below.

## Why pruning before deduplication is safe

Every raw matrix is retained, safely pruned, or mapped to a saved representative by an explicit integral unimodular Gram isometry. Signature matching is not used as proof of equivalence. Failure to detect an isometry would only retain extra cases; an accepted map is checked directly.

The saved representatives are actual raw flag matrices, rather than new reduced bases with an unproved prefix condition. Their prefix perpendicular vectors are therefore shortest. A raw parent isometry need not preserve the earlier marked subflag: the next extension depends on the parent lattice and all its discriminant classes, so transporting the entire extension across the isometry is sufficient. The chosen representative independently has a valid shortest-dual subflag. There is no need to classify marked flags up to automorphism.

The lifting lower bound for the next step is intrinsic because the previous-to-parent determinant ratio equals the parent's dual minimum. In fact using the norm of any explicit nonzero dual vector in that inequality would only weaken the prune, so a larger ratio could not accidentally remove a legitimate next extension. The optimized extension kernel separately checks the claimed dual minimum in each parent it processes.

Thus a different previously marked flag in an isometric parent cannot rescue a case removed by the necessary lifting test, and passing to the representatives cannot lose extensions.
