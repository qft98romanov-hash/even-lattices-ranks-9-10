# Точные сертификаты теоремы о решётках ранга девять

## Сертифицируемое утверждение

Итоговый пакет предназначен для проверки следующей
компьютерно-ассистированной теоремы.

> Если `L` — положительно определённая чётная целочисленная решётка ранга 9
> и `min(L) >= 6`, то `det(L) >= 21870`.

В препринте отдельно приведена решётка `K_9` с минимумом 6 и определителем
21870. Поэтому сочетание нижней оценки с этим примером даёт точное значение
минимального определителя 21870.

Пакет содержит отдельную точную проверку приведённого примера `K_9`. Он
**не** утверждает единственности оптимизатора или полной классификации всех
решёток ранга 9.

## Схема доказательства

Предположим противное: `det(L_9) < 21870`. Последовательный выбор примитивных
гиперплоских сечений по кратчайшим векторам двойственных решёток задаёт
насыщенный флаг

```text
L_1 < L_2 < ... < L_9.
```

Определители его членов попадают в следующие точные окна:

| ранг | окно определителя | сравнение |
|---:|---:|---:|
| 1 | 6 | -- |
| 2 | 27--39 | 0 или 3 по модулю 4 |
| 3 | 108--178 | 0 по модулю 2 |
| 4 | 324--633 | 0 или 1 по модулю 4 |
| 5 | 972--1894 | 0 по модулю 2 |
| 6 | 2187--4647 | 0 или 3 по модулю 4 |
| 7 | 4374--9492 | 0 по модулю 2 |
| 8 | 6564--15908 | 0 или 1 по модулю 4 |

Точный перебор нижней части флага даёт:

```text
ранг:           1   2   3   4    5    6
классы:         1   5  14  47  118  138
новые формы:        7  52 279 1456 1905
```

Расширение всех 138 классов ранга 6 даёт 2235 сырых форм ранга 7. Если
`d_i = det(L_i)` и `lambda_1(L_7^*) = d_6/d_7`, то условие кратчайшей
нормали на следующем шаге влечёт

```text
d_8 >= 3 d_7^2 / (4 d_6).
```

Из 31 пары определителей после этого остаются лишь шесть, содержащие 96 из
2235 сырых форм; остальные 25 пар, или 2139 форм, исключаются. Явные
целочисленные изометрии сводят 96 сырых форм к шести классам ранга 7.
Независимые точные сертификаты остаточных ветвей показывают, что ни один из
этих классов не продолжается до решётки ранга 9 с определителем меньше
21870.

| `(d_6,d_7)` | класс ранга 7 | точное исключение |
|---:|---|---:|
| `(2187,4374)` | `sqrt(3)E_7` | `d_9 >= 21870` |
| `(2187,6318)` | `H_6318` | `d_9 >= 32076` |
| `(2835,7722)` | `D_7722` | нет согласованного с флагом `L_8`; для избыточного неограниченного кандидата `d_9 >= 36504` |
| `(4096,8192)` | `4E_7^*` | `d_8 >= 20480 > 15908` |
| `(3240,8100)` | `R_8100` | `d_8 >= 18225 > 15908` |
| `(3267,7986)` | `R_7986` | единственный согласованный с флагом класс `L_8`, `d_8=14641`; затем `d_9 >= 39930` |

Окна насыщенного флага используют классические точные значения эрмитовых
констант в размерностях не выше восьми и неравенство Морделла. Эти
математические входы являются предпосылками конечного сертификата и не
доказываются программами заново.

## Арифметика и программное обеспечение

Все решения, существенные для доказательства, принимаются в целых числах или
в `fractions.Fraction`. Перебор эллипсоидов использует точное LDL-разложение
и точные целочисленные квадратные корни. Изометрии снабжены явными
унимодулярными целочисленными матрицами. Сравнения с плавающей точкой не
используются как доказательные шаги.

Требования:

- CPython 3.12 или новее;
- только стандартная библиотека Python для итоговых сертификатов;
- POSIX shell и `sha256sum` для общего сценария запуска.

Некоторые исторические поисковые программы используют NumPy. Они не входят
в логический сертификат и исключены из итогового архива.

## Воспроизведение

В окончательный архив входит `run_all_checks.sh`. После распаковки следует
выполнить

```bash
./run_all_checks.sh
```

Сценарий проверяет закреплённые хеши входных данных и запускает точные
аудит-программы. Наиболее дорогой перебор ранга 6 в ранг 7 распространяется
в виде сохранённых частей и проверяется точно. Команды полной повторной
генерации приведены в `RUN_ORDER.md`.

Для побайтового воспроизведения всей нижней части флага и всех четырёх частей
ранга 7 предназначен `./run_full_regeneration.sh`. Он работает существенно
дольше, чем аудит сохранённых сертификатов.

Архив также содержит успешно проверенный дополнительный сертификат полной
ветви `sqrt(3)E_6`. Его необходимые следствия для E7 и H6318 повторно
проверяются сценарием `run_all_checks.sh`; более тяжёлое избыточное вычисление
сохранено вместе с транскриптом и хешами, но по умолчанию не запускается.

Дополнительные файлы:

- `ASSUMPTIONS_RU.md` — математические предпосылки и границы результата;
- `RUN_ORDER.md` — точный порядок генерации и аудита;
- `CLAIMS_TO_CERTIFICATES.md` — соответствие утверждений сертификатам;
- `SHA256SUMS` — контрольные суммы всех файлов выпуска.

## Статус выпуска

Все семейства сертификатов из `CLAIMS_TO_CERTIFICATES.md` присутствуют.
Архив выпуска проверен командой `unzip -t`, распакован в новую временную
директорию и проверен там командой `sha256sum -c SHA256SUMS`.
