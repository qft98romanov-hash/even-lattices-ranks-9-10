# English reading map

Start with [the current manuscript](../manuscript/paper.pdf), or its
[editable LaTeX source](../manuscript/paper.tex). The `.txt` source is identical
to the `.tex` source and can be pasted into Overleaf with XeLaTeX selected.

All current mathematical results and their background are available in English.
The historical certificate tree is retained byte for byte, including Russian
originals whose alteration would invalidate the archived identity manifest.
Use the English counterparts below; historical records retain their original
dates and are not the current open-problem list.

The two bilingual report-authoring scripts are historical build records, not

builds using `python scripts/build_paper.py` from the repository root.

historical absolute working paths and are not maintained entrypoints. Use the
