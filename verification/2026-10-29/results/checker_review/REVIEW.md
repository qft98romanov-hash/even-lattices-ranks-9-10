# Adversarial review of the additional verification code

This review found no concrete mathematical defect in the reviewed implementation. It is a code review and finite computational cross-check, not a formal proof audit of every theorem in the manuscript.

## Exact checker and input provenance

Reviewed `check_exact.py` and `export_inputs.py`. The latter extracts literal data by AST parsing or JSON reading; it does not execute or import the archived verification algorithms. Source hashes are recorded. Expected values are used for comparisons after computing the invariants.

The exact ellipsoid search uses a rational factorization `A = L D L^T` and enumerates coordinates in reverse order. For fixed higher coordinates, the contribution at coordinate `i` is `D[i] * (x[i] + offset)^2`. The integer candidate interval encloses the real interval determined by the remaining budget: its radius is an exact integer ceiling of the square root, and its endpoints deliberately extend beyond the necessary interval. Every candidate is filtered by its exact rational cost. Thus equality at the boundary is retained. Leaf norms are independently recomputed from the original matrix, duplicates are rejected, and sign symmetry is checked. This argument concerns the implementation's finite search for a supplied positive definite form and bound.

Positive definiteness is checked exactly by principal minors. Integrality and even diagonal entries precede determinant and Smith-form calculations. Smith invariants and ranks over finite fields are computed over exact domains.

The shortest-dual-vector kernel construction is valid for the returned normals: their first eight entries vanish, and their final pair `(a,b)` has gcd one. The eight standard basis vectors together with `(0,...,0,b,-a)` form the full integral kernel, not a proper sublattice. This verifies the kernels of the shortest dual pairs in the two supplied rank-10 lattices. It does not classify arbitrary rank-9 sections or all rank-10 lattices.

The perfection check uses the upper-triangular entries of `v v^T` for minimal vectors and establishes exact rank 45, including a nonzero exact minor. Duplicating both signs is unnecessary because their outer products coincide.

## Independent small-form stress test

Run from this directory's add-on root:

```sh
python tests/review_enumerator.py
```

Result: **PASS**, 27 complete brute-force comparisons, reproducible seed `20261029`, dimensions 1--3, and 55 boundary points. Inputs include rational scaling, skew forms, zero bounds, and bounds chosen from exact vector norms. The reference search obtains independent coordinate bounds from `x_i^2 <= B * (A^-1)[i,i]`, using an integer loop, then checks every integer point in the resulting box. It does not reuse the checker's LDL recursion or square-root helper. Full inputs and counts are in `enumerator_adversarial.json`.

These tests exercise defects such as missing endpoints, an incorrect factor of two, and off-diagonal sign errors. They do not replace the mathematical search-completeness argument or prove the global determinant lower bound.

## Other systems

- **PARI/GP:** Static review found the form normalization, dual rescaling, returned-vector norm checks, and isometry-certificate direction consistent. The recorded PARI 2.19.0 run passes. The complete returned nonzero coordinate sets through norm 10 agree with the exact checker: 582 vectors for K9, 1266 for K10, and 1272 for K10_alt. PARI's numerical enumeration is corroboration; the separate rational enumerator supplies the completeness argument.
- **GAP:** The separate exact reverse-LDL search, row-reflection action, and stabilizer computations are consistent. The recorded GAP 4.12.1 run passes. All 120 root reflections are checked to belong to the group generated by the eight basis reflections. The admissible partner set is checked invariant before its stabilizer orbit decomposition. This checks the stated finite E8 glue-orbit computation, not global rank-10 equality classification.
- **Magma:** Static review only. The supplied Gram matrix, true unrescaled dual, sign-pair convention, and coordinate-row isometry and automorphism certificate checks are consistent with the documented API. No Magma execution is claimed.
- **SageMath:** Static review only. `QuadraticForm(2*G)` has value `x^T G x`; the strict enumeration upper bound is shifted by one, and both signs are requested. Smith and isometry matrix identities are checked exactly. Sage's PARI backend means this is not an independent enumeration engine from PARI/GP. No SageMath execution is claimed.
- **OSCAR:** Static review only. The short-vector pair convention, primitive-sublattice argument order, scaled A2 complements, determinant/index relations, and isotropic glue quotient are mathematically consistent. The code checks the explicit decompositions and quotients; it does not enumerate every glue map. Julia namespace and API type resolution still require an actual OSCAR run. No OSCAR execution is claimed.

## Limits

The audit corroborates the explicit forms, shell counts, dual vectors, primitive kernels, perfection, and finite orbit statements covered by these programs. It does not certify a classification theorem, establish scientific novelty, check every ambient embedding, or provide formal proof-assistant verification. The unexecuted CAS adapters must remain marked `NOT_RUN` until their native systems complete successfully.
